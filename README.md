# uber-data-analytics-dashboard
Uber Data Analytics Dashboard is a data visualization project developed using Python, Flask. It analyzes ride bookings, revenue, vehicle types, driver status, payment methods, and city-wise ride performance through interactive dashboards and graphical reports. The project helps users understand ride trends and business performance.

Uber Data Analytics Dashboard is a modern web-based application developed using Python Flask. It provides an interactive analytics workspace to explore Uber ride data, analyze vehicle performance, monitor customer behaviour, track revenue, and compare city-wise trends. The project features a responsive dark-themed interface, animated Uber bike illustration, interactive navigation, and data visualization for better business insights.

## Technologies Used
This Uber Data Analytics project is developed using modern technologies for web development, database management, data analysis, and visualization.

- **Python:** Backend programming and data processing.
- **Flask:** Building the web application.
- **HTML5:** Creating web page structure.
- **CSS3:** Styling and responsive dashboard design.
- **JavaScript:** Interactive dashboard functionality.
- **SQLite:** Storing and managing project data.
- **Pandas:** Data cleaning and analysis.
- **Matplotlib:** Creating charts and visualizations.
